This site is authored in LaTeX and converted to static HTML with
\href{https://github.com/latex2html/latex2html}{LaTeX2HTML}.

\section{Pipeline}

Each public page is an \texttt{index.tex} document.  The build runs LaTeX2HTML
in single-page, navigation-free, HTML5 mode and renders mathematical material as SVG.
The generated \texttt{public/} directory is then deployed by rsync.

\section{Local build}

\begin{verbatim}
./scripts/build
\end{verbatim}

The bootstrap helper pins LaTeX2HTML commit
\texttt{8de149ed754a1cadd944b04efb3e2a42026c5f0c} and installs it under the
repository-local, ignored \texttt{.tools/} directory.
